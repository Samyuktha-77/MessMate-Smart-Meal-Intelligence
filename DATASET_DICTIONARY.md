# Dataset Dictionary

The generated file is `data/mess_food_data.csv`. It contains 1,095 simulated calendar days × 3 meals = 3,285 rows by default.

| Column | Type | Role | Description |
|---|---|---|---|
| date | Date | Identifier/time | Simulated meal date |
| meal_type | Category | Feature | Breakfast, Lunch or Dinner |
| day_of_week | Category | Feature | Day name |
| is_weekend | Integer | Feature | 1 for Saturday/Sunday |
| is_holiday | Integer | Feature | Simulated holiday indicator |
| exam_period | Integer | Feature | Simulated exam-period indicator |
| weather | Category | Feature | Sunny, Cloudy or Rainy |
| menu_category | Category | Feature | Broad simulated menu category |
| expected_students | Integer | Feature | Simulated expected attendance |
| portions_prepared | Integer | Feature | Planned/prepared portions |
| portions_consumed | Integer | Target | Simulated consumed portions |
| food_waste | Integer | Target | Simulated leftover portions |

## Prediction inputs
Demand model: meal_type, day_of_week, weather, menu_category, is_weekend, is_holiday, exam_period, expected_students.

Waste model: the same context plus portions_prepared.

Actual consumption and actual waste are targets only and are not model inputs.

## Data provenance
Generated by `generate_data.py` using assumed rules and random variation. No actual student or university records are included. This must be stated in the report and presentation.
